# SkyForge Helper branding

SkyForge Helper is the official project name. Developer and copyright holder:
**Beluga_8292**, © 2026. The intended GitHub repository name is **SkyForge-Helper**;
an account/organization and official repository URL have not yet been verified.

Forks and modifications are permitted by the MIT License. Keep the copyright
notice and license when distributing copies or substantial portions.

Please give derivative projects a distinct name and visual identity. Clearly
identify unofficial builds and their publisher; do not describe a third-party
build as an official SkyForge Helper release. Verify official installers against
links and checksums published by the project owner once a release is approved.

These branding recommendations do not add restrictions to the MIT code license.
MIT alone is not a comprehensive enforceable trademark/no-impersonation policy.
Any mandatory separate brand-use terms require an independently reviewed legal
policy; this repository does not invent one or claim a trademark registration.

The published **SkyBlock Companion 0.5.0-rc.5** keeps its original name. Current
source has a new UI brand. Legacy bundle/install identity is deliberately retained
until the compatibility migration in [REBRANDING.md](docs/REBRANDING.md) is tested.
